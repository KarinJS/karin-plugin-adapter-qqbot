title: 配置项
description: config.json 的字段。

## 示例

```json
[
  {
    "appId": "1234567890",
    "secret": "your-secret",
    "event": { "type": 2 }
  }
]
```

除 `appId` 和 `secret` 外都有默认值，缺省字段会自动补上。

## 基础字段

| 字段          | 类型    | 默认 | 说明                                    |
| ------------- | ------- | ---- | --------------------------------------- |
| `name`        | string  |      | 显示名称，多机器人时用来区分            |
| `appId`       | string  | 必填 | 开放平台的机器人 AppID                  |
| `secret`      | string  | 必填 | AppSecret，用来换 access_token          |
| `qqEnable`    | boolean | true | 接收单聊和群聊事件                      |
| `guildEnable` | boolean | true | 接收频道和频道私信事件                  |
| `guildMode`   | 0 / 1   | 0    | 0 公域，只收 @ 消息；1 私域，收全部消息 |

## 文本预处理

`regex` 在消息进入 Karin 前改写文本，按数组顺序执行。常见用法是把 `/` 换成 `#`。

```json
"regex": [{ "reg": "^/", "rep": "#" }]
```

只改文本，消息 ID 和引用关系不变。

## 事件接收

| `event.type` | 说明                                        |
| ------------ | ------------------------------------------- |
| 0            | 关闭事件，只保留 API 调用                   |
| 1            | Webhook，需要公网可访问                     |
| 2            | WebSocket，不需要公网地址，断线重连（默认） |

Webhook 回调地址填 `https://你的域名/qqbot/webhook`。适配器会校验签名和 `x-bot-appid`。

## 消息缓存

默认关闭。开启后 `bot.getMsg`、撤回和引用解析在进程重启后仍然可用。

| 字段                    | 默认     | 说明                                                                             |
| ----------------------- | -------- | -------------------------------------------------------------------------------- |
| `messageCache.enable`   | false    | 启用 SQLite 缓存                                                                 |
| `messageCache.self`     | false    | 缓存机器人自己发出的消息                                                         |
| `messageCache.level`    | standard | minimal 只存 ID 和引用；standard 加文本、表情、媒体路径；full 存全部可缓存消息段 |
| `messageCache.ttlHours` | 24       | 保留小时数，1 到 720                                                             |
| `messageCache.maxRows`  | 200000   | 最大行数，1000 到 5,000,000，超出后删除最旧记录                                  |

多个机器人共用缓存表，`ttlHours` 和 `maxRows` 取最大值。

## 多机器人

每个数组元素是一条独立连接，`appId` 不能重复，重复时以最后一次为准。

旧配置里的 `markdown` 字段会被忽略，下次保存时自动清除。

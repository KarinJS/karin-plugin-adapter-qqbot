QQBot 不改变 Karin 的插件写法。`karin.command`、`e.reply`、`segment`、`karin.accept` 以 [Karin 官方文档](https://karinjs.com)为准。

- [图片与文件](/docs/develop/media) 媒体处理顺序、`fileToUrl`、素材管理。

## 拿到适配器实例

`e.bot` 是 `AdapterType`，调用官方接口前收窄成 `AdapterQQBot`。

```ts twoslash
import karin from 'node-karin'
import type { AdapterQQBot } from '@karinjs/adapter-qqbot'

export const me = karin.command(/^#me$/i, async (e) => {
  const bot = e.bot as AdapterQQBot
  const info = await bot.super.meta.getMe()
  //    ^?
  await e.reply(`我是 ${info.username}`)
})
```

`info` 的类型是 `GetMeResponse`。适配器不会替换 `e.bot`，其他插件按 Karin 标准字段读消息不用改。

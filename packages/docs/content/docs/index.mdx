---
title: QQBot 适配器文档
description: 把 QQ 官方机器人接进 Karin。
---

`@karinjs/adapter-qqbot` 接收单聊、群聊、频道和频道私信事件，把 Karin 消息段转成 QQ 官方消息，并把官方 OpenAPI 挂在 `bot.super`。

</Cards>

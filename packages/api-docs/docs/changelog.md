# [#](#变更记录) 变更记录

## [#](#_20261026) 20261026

### [#](#新增) 新增

* **群聊 @全部成员**：群聊场景文本消息、markdown 消息支持使用 `<qqbot-at-everyone />` @全部成员，机器人需为该群管理员，且每个群每天仅可发送 1 次。

## [#](#_20261021) 20261021

### [#](#新增-2) 新增

* 新增**素材管理**：支持将图片上传至平台，获取 `qqbot-media://` 引用后在 Markdown 消息中使用。

## [#](#_20260916) 20260916

### [#](#优化) 优化

* **生成分享链接（`/v2/generate_url_link`）** 修正请求和响应字段说明。
* **消息事件（群 @ 消息、群消息、单聊消息）**：`ark_type` 枚举新增 `picture`（图片）取值说明。

## [#](#_20260903) 20260903

### [#](#新增-3) 新增

* **群管理接口**

  * 新增**群成员管理**相关接口：

    * 获取群成员信息
    * 群成员批量移除
    * 群黑名单查询
    * 群黑名单操作

### [#](#优化-2) 优化

* 修改了部分接口描述。

## [#](#_20260812) 20260812

### [#](#新增-4) 新增

* **自定义菜单**

  * 新增查询、修改全局自定义菜单接口。
* **指令面板**

  * 新增指令面板管理接口，支持查询列表、创建、查询详情、修改、删除及修改关联对象。

## [#](#_20260810) 20260810

### [#](#优化-3) 优化

* **接口调用域名统一**：所有接口调用域名统一为 `api.bot.qq.com`。

### [#](#新增-5) 新增

* **群消息 / C2C 消息**

  * 发送 Markdown 消息：新增可选参数 `force_verify_image_resource`。开启后，当图片资源转存失败时，将中断消息发送并返回失败（默认关闭，保持原有行为）。
* **群管理接口**

  * 新增**群禁言管理**相关接口：
    * 查询用户禁言状态
    * 设置用户禁言
  * 新增**入群申请审批**相关接口：
    * 拉取入群申请列表
    * 审批入群请求
  * 新增**入群自动审批策略**相关接口。
* **事件**

  * 新增用户入群申请事件。
